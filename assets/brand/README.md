# Brand

honeycomb shares its brand with the sister project [Framehive](https://github.com/polandy/framehive):
the same six viewfinder corners, colours and typeface. The two cells are what sets honeycomb apart.

## Logo

Six viewfinder corners are arranged as a hexagon around two honeycomb cells side by side. The
corners are the frame, the cells are a RAW+JPEG pair, and the filled cell against the outlined
one is the decision: one picture kept, one still in question. Next to the mark is the wordmark
"honeycomb" in lower case.

| File | Use |
|---|---|
| `logo-mark.svg` | Mark only, for light backgrounds |
| `logo-mark-dark.svg` | Mark only, for dark backgrounds |
| `logo-horizontal-light.svg` | Mark and wordmark, for light backgrounds |
| `logo-horizontal-dark.svg` | Mark and wordmark, for dark backgrounds |
| `app-icon.svg` | App icon, 512 × 512, rounded tile |
| `app-icon-maskable.svg` | App icon, full bleed, with the mark inside the safe zone |
| `favicon.svg` | Heavier cut for 16–32 px. It follows the browser's light or dark scheme |
| `../../img/app.svg` | Nextcloud navigation icon, heavier cut in one colour (Ink) |
| `../../img/app-dark.svg` | The same in Paper, for dark themes |

The SVG files are generated by `generate.py`. Edit the script, not the outputs:

```sh
uv run --no-project --with fonttools==4.66.1 --with uharfbuzz==0.56.3 \
    assets/brand/generate.py
```

## Colours

| Name | Value | Use |
|---|---|---|
| Honey | `#F4A51C` | The filled cell. It is the only accent, so keep it small |
| Ink | `#17150F` | Frame, outlined cell and text on light, and the app icon tile |
| Paper | `#FBF8F1` | Frame, outlined cell and text on dark |

The filled cell stays honey on every background and always sits on the left. Never recolour,
rotate or mirror the mark, and keep a clear space of at least one cell's width around it. Use the
heavier cut below 32 px. The Nextcloud icons are one colour because Nextcloud tints them itself.

## Type

The wordmark is Sora SemiBold with −0.03 em tracking. The glyphs are outlined to paths, so the
logo renders without the font. Sora is licensed under the SIL Open Font License 1.1. The script
fetches it from a pinned google/fonts commit and checks its SHA-256; nothing else touches the
network.
