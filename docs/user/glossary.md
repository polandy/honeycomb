# Glossary

The words honeycomb uses, in brief: the ones a cull needs. The app and this documentation use
them and no synonyms.

| Word | Meaning |
|---|---|
| **photo** | What you see and decide on: one picture. A pair or a single. |
| **pair** | A RAW file and a rendered file with the same name, belonging together. |
| **single** | A photo with only one file: *JPG only* or *RAW only*. |
| **member** | One file of a photo: its RAW file or its rendered file. |
| **RAW file** | A camera RAW file, such as `.NEF` or `.CR2`; the types are a setting. |
| **rendered file** | A camera-made image file, such as a JPEG or HEIF. Shown in the app. |
| **sidecar** | The `.xmp` file next to a photo that holds its metadata for other programs. |
| **rating** | 0 to 5 stars; 0 means unrated. |
| **colour label** | One of digiKam's nine colours, or none. |
| **flag** | *Picked*, *Rejected* or *Unflagged*; digiKam calls it a pick label. |
| **Pick** | Mark a photo to keep. |
| **Reject** | Mark a photo to throw away. |
| **Unflag** | Take the pick or reject off a photo. |
| **Keep RAW** | A marker that keeps a pair's RAW file when *Remove RAWs* runs. |
| **rateable** | A photo whose folder you may change, so you can rate, label, flag and tag it. |
| **read only** | A photo whose folder you may not change: it shows a lock and nothing can be set. |
| **take-over** | Recording once the flag and *Keep RAW* a photo's sidecars state, when honeycomb first sees it. |
| **cull** | Going through a folder set and rating, labelling, flagging and deleting photos. |
| **folder set** | The folders one cull covers: the ticked ones and, if you include them, their subfolders. |
| **library root** | A folder of your own files that *Folders* lists and counts; together they are the *Library*. |
| **done** | A folder you marked as gone through; new photos leave it done and show as *n new*. |
| **undecided** | A photo with no flag, and not in a series you marked done. |
| **series** | Photos taken within a short time that look alike, compared side by side to pick the best. |
| **sharpest** | The clearly sharpest photo of a series; a hint only, it picks nothing. |
| **burst** | Photos taken at most 3 seconds apart, used to rank folders. Not a *series*. |
| **similarity** | How alike two photos look; honeycomb computes it ahead of a cull to group series. |
| **reject review** | The grid of all rejected photos, where you can rescue one before deleting. |
| **Remove RAWs** | Move the RAW files you do not keep to the trash bin and keep the JPEGs. |
| **tag** | A path of names such as `Places/Italy/Dolomites` given to a photo. |
| **selection** | The photos you marked for a bulk action. |
| **filter** | A condition on rating, colour label, flag, pairing, *Keep RAW*, tags or folder. |
| **resume position** | Where you stopped in a folder set; kept on the server, so you go on on any device. |
