Tag entry mockup (tags concept, PR #100)

  • grid: click, Shift/Ctrl-click or ←→↑↓, Shift+arrows, CtrlA select
  • touch: long-press a tile for selection mode, tap toggles, bar: Tags, Done; tap outside it opens the loupe
  • Enter / double-click: loupe
  • T tag entry for the loupe picture or the selection
  • type: filter by substring
  • Tab / ShiftTab (or ↓↑): cycle the matches into the field
  • Enter assigns exactly the field (creates if new)
  • / makes a level
  • dashed chip: only some selected pictures have it
  • chip × or Backspace in empty field: remove (from all selected)
  • Esc close entry, then loupe
